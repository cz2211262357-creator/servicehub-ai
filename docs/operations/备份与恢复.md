# 备份与恢复手册

MySQL、私有上传文件是必须一起保留的权威数据。Redis AOF 用于会话、任务投递与向量索引持久化；Redis 数据丢失后登录失效，数据库中的待执行/过期任务由 Worker 对账重新投递。向量数据丢失后可通过文档新版本重新索引。当前没有一键全量索引重建工具，恢复时应保留 Redis AOF，或逐文档重新上传并等待索引完成。

以下是本地运维步骤，尚未作为跨主机灾难恢复演练。正式部署需设置加密异地副本与保留策略。

## 备份

1. 停止 API 与 Worker 写入，保留 MySQL 运行。创建 .data/backups 下带日期的新目录。
2. 用数据库一致性导出，保存 SQL。凭证来自容器环境，不直接写在命令参数。
3. 复制 .data/uploads 与配置模板。真实 .env 单独加密保管。
4. 停止 Redis 后复制 .data/redis 的完整 AOF 目录，避免复制正在修改的多个 AOF 段。
5. 恢复 Redis/API/Worker，检查 /api/v1/health/ready 与任务列表。

~~~powershell
. .\scripts\env.ps1
$backupPath = Join-Path $ProjectRoot ('.data\backups\' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
New-Item -ItemType Directory -Path $backupPath | Out-Null
docker compose --profile app stop api worker
docker compose exec -T mysql sh -c 'MYSQL_PWD="$MYSQL_ROOT_PASSWORD" mysqldump -u root --single-transaction --routines --default-character-set=utf8mb4 servicehub' > (Join-Path $backupPath 'servicehub.sql')
if ($LASTEXITCODE -ne 0) { throw 'Database backup failed' }
Copy-Item -LiteralPath '.data\uploads' -Destination $backupPath -Recurse
docker compose stop redis
Copy-Item -LiteralPath '.data\redis' -Destination $backupPath -Recurse
docker compose start redis
docker compose --profile app start api worker
~~~

使用 PowerShell 7，以 UTF-8 保存文本 SQL。备份目录放在本项目是开发便利，不能代替独立介质副本。

## 恢复

先在新的隔离实例/目录试还原，禁止直接覆盖唯一一份数据。新建同版本 MySQL 8.4，创建空数据库和最小权限账号，导入 SQL，再挂载对应 uploads 与 Redis AOF 目录。服务停止时替换卷，确认宿主目标路径位于指定恢复目录。不要让新旧实例同时挂载同一 MySQL 数据目录。

按配置启动 MySQL/Redis，运行 Alembic upgrade head 后启动 API/Worker。验证管理员登录、一个客户订单、原始引用文档下载、历史会话、任务恢复与售后状态，确认 UTC 时间、金额和租户隔离。不要通过重新 seed 冒充历史数据恢复。

## 故障处理

- API ready 为 503：先查看 docker compose ps 与服务日志，检查数据库连接、Redis、磁盘和容器健康。
- 文档索引失败：在知识库或任务页查看错误代码；确认模型配置、源文件存在、PDF 含文本层。管理员可对最终失败任务重试。
- 模型限流或超时：任务会有限重试；保留供应商错误代码，客户可转人工。不得切换到假回答来隐藏故障。
- Worker 停止：重启后等待租约过期与对账；不要手改成功状态。默认对账间隔约 15 秒、任务租约 60 秒。
- Redis 内存满：noeviction 会明确报错。扩容并检查历史索引保留；不要静默驱逐会话/锁来维持表面可用。
- 凭证变更：更新本地/部署密钥后重启服务。禁止提交 .env；运行状态页面只显示是否配置，不显示密钥值。

生产配置 SERVICEHUB_ENVIRONMENT=production 时要求 HTTPS 来源、Secure Cookie 和独立数据库密码。Compose 默认仅绑定 127.0.0.1，是本地部署配置；外网部署需在受控入口终止 TLS，并配置对应域名与最小暴露端口。
