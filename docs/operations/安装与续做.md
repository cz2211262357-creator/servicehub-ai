2. 启动 D:/研究生/简历1/qz-project/.tools/docker/Docker Desktop.exe，等待引擎启动。
3. 在本项目继续原会话，先检查 Docker 引擎；若仍显示虚拟化不可用，核对 WSL 与 BIOS 虚拟化状态，不要重复下载安装器。

