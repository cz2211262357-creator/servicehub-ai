## 模型与工程

- 前端 React / TypeScript；后端 FastAPI / SQLAlchemy asyncio；MySQL 8.4 为业务权威源；Redis 8.4 负责会话、限流、并发槽、Streams、实时通知和 HNSW。
- 对话使用百炼 qwen-plus；向量使用 text-embedding-v4，1024 维。两类 Key 已保存在忽略的本地 .env，前端不持有 Key。
- 客服、客户、管理员角色与租户隔离均在服务端校验。售后必须由客户明确确认；Agent 只能查政策、查本人订单和准备草稿。
- 已实现幂等消息/工单、并发抢单、事务 Outbox、任务租约与执行版本、接管代次围栏、断线事件补放、任务自动重试及管理员恢复。
- 最终修复包括独立 Worker 调度、失败终态与恢复快照、会话切换隔离、有效知识版本预过滤和精确版本引用下载。旧向量索引可原地补齐版本元数据，无需为此重新调用 embedding。

## 重启后启动

先启动 D:\研究生\简历1\qz-project\.tools\docker\Docker Desktop.exe，等待引擎就绪。PowerShell 执行：

~~~powershell
Set-Location 'D:\研究生\简历1\qz-project'
. .\scripts\env.ps1
docker compose --profile app up -d --no-build --wait api worker web
docker compose --profile app restart web
~~~

重新打开 http://localhost:8080。恢复已有数据无需重新执行 seed。源码开发、镜像重建及 PyCharm 解释器设置见 [PyCharm 与启动](operations/PyCharm与启动.md)。无需重装 Docker 或 WSL。
