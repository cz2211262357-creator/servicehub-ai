## 数据移交的边界

仅导出业务表与知识元数据/文件，不复制密码哈希、登录会话、旧run/job、Outbox、工具执行或旧索引。所有历史消息进入默认话题供查看，作为旧执行上下文被排除；旧未确认草稿过期。知识文件由Java重新上传版本并构建索引后才向客户启用。

SQL导入失败整笔回滚，并只清理本批拥有的提升文件。发送COMMIT前即设置文件保留标志；回执丢失、任务取消或Ctrl+C时保留文件并记录commit_outcome_unknown，不能用瞬时查不到标记证明回滚，不能宣称数据库与文件系统存在共同原子事务。

所有真实业务资料、移交包、凭证、原始报告与测试临时文件位于忽略目录。公开仓库只沿用原公开Git历史制作干净源码快照，不推送私有开发历史或个人简历。
