# 业务操作

## 操作流程

1. 以管理员登录，查看知识库中的售后政策是否已就绪，查看运行配置已接入在线模型。可上传自己的 Markdown/TXT/文本 PDF，等待真实 Embedding 完成。
2. 以 customer@example.com 登录，创建会话，问“签收后七天内可以退货吗，需要保留什么？”。回答应来自实际知识片段，引用下载需要当前登录身份。
3. 发送“查询订单 SH20261021001，商品无法开机，帮我准备退货申请”。Agent 只能调用已授权工具，查当前客户订单并生成草稿。确认前正式工单不存在。
4. 点击草稿的确认提交，进入售后工单查看待审核状态。重复确认使用同一幂等键，只产生一个结果。
5. 客户点击转人工；用另一浏览器/无痕窗口以 agent@example.com 登录，接单、人工回复。客户应立即收到同一条持久化消息。人工接管后迟到的 AI 不能新增正式回复。
6. 客服将工单依次改为审核中、通过、已完成，查看时间线。非法跨状态操作会返回冲突并写入审计。
7. 管理员查看真实运营聚合、任务状态与审计。换第二企业/第二客户核对订单与会话不可串读。

种子是虚构商家数据，模型接口与所有业务写入均真实执行。切勿把本地种子写成真实商业客户或生产接入经历。
