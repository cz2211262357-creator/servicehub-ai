# P15 错发商品处理 SOP

适用说明：合成商家政策与评估资料，版本日期 2026-10-29；不是任何真实商家的现行承诺。

合成商家星桥商城确认订单、实际收到商品和 SKU 不一致后，已签收 15 天内可准备 reason_code=WRONG_ITEM 的 RETURN 或 EXCHANGE 草稿。只基于本人订单，不能因一个用户知道他人订单号就披露他人的商品或地址。

草稿应关联当前明确选择的订单；用户修改订单号时重新核查归属与资格，旧订单的草稿不能自动变成新订单授权。换货库存、补发日期和退款到账日均须人工或外部系统确认。
