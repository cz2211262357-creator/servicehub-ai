# P02 商品完好、试穿与合理查验

适用说明：合成商家政策与评估资料，版本日期 2026-10-29；不是任何真实商家的现行承诺。

星桥商城区分完好、合理查验、已使用和信息不明。为确认款式尺码作合理试穿、打开普通外包装检查配件，不直接等于商品不完好；明显污渍、磨损、洗涤、私自改装等需人工判断。标签和附件是否齐全、是否发生实际使用均应依据订单关联的可信售后事实。

系统的 return_condition 为 intact 或 opened_inspected 时，可以继续校验无理由窗口；为 used 时不自动准备无理由退货草稿；为 unknown 时先澄清或转人工。客服不能仅根据用户一句“肯定完好”覆盖后台未知或矛盾的事实。
