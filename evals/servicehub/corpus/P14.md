# P14 运输破损与安全异常 SOP

适用说明：合成商家政策与评估资料，版本日期 2026-10-29；不是任何真实商家的现行承诺。

星桥合成售后 SOP：记录外包装、商品损坏和签收情况，查询本人订单。已确认运输破损、已签收 15 天内且无危险因素时，可准备 reason_code=LOGISTICS_DAMAGE 的 RETURN 或 EXCHANGE 草稿，正式工单须客户确认。

破损涉玻璃割伤、电池鼓包、冒烟、漏液或人身伤害时标记人工安全复核，不直接安排普通退件，不要求客户继续使用或自行拆解。保存必要证据即可，不收集无关身份证、完整银行卡或验证码。
