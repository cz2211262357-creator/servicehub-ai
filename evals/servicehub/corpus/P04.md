# P04 普通电子产品开箱与激活

适用说明：合成商家政策与评估资料，版本日期 2026-10-29；不是任何真实商家的现行承诺。

合成商家星桥商城对普通未定制电子产品不以“拆了包装”一概拒绝无理由退货。签收 7 天内、仅合理开箱查验、商品及配件完好且后台没有已确认排除情形，可继续准备 RETURN 草稿。

已激活、绑定不可解除账号、实际长期使用、缺失序列号等情形可能涉及商品性质或价值变化，应标记 requires_manual_review，由人工结合购买时的提示、确认记录及事实核验。不能由模型自行断言全部激活电子产品当然不退，也不能擅自把 unknown 改为 intact。
