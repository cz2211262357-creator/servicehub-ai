# P07 定制商品与制作错误

适用说明：合成商家政策与评估资料，版本日期 2026-10-29；不是任何真实商家的现行承诺。

合成商家星桥商城中 custom 类为按消费者指定尺寸、刻字、图案等实际定作的商品；这类商品不走无理由自动退货。仅因“页面写了定制”却无真实定作事实的争议，应人工核验，不能机械套用例外。

刻字与确认稿不符、制作尺寸错误或已确认质量缺陷仍应受理。签收 15 天内可按本商家加宽承诺准备 RETURN 或 EXCHANGE 草稿。存在设计稿争议、定制事实不明、已经安装等复杂情况设置人工复核，模型不能替代鉴定。
